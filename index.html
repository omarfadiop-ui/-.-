☀️ 1. وجبة الإفطار

• الوجبة:

بيضتان مسلوقتان + خبز أسمر + خيار وطماطم + كأس حليب دافئ (أو شوفان بالفاكهة والعسل).

🍗 2. وجبة الغداء

• الوجبة:

دجاج مشوي/مسلوق أو تونة + أرز + سلطة خضراء مع ليمون.

🍎 3. السناك الصحي

• الوجبة:

ثمرة رمان أو تفاحة/موزة + حفنة لوز خفيف.

🌙 4. وجبة العشاء

• الوجبة:

سندويتش لبنة أو مقدوس + تونة وسلطة (أو زبادي وخيار).
